Om mig

Andrey Fedotkin

Mitt namn är Andrey Fedotkin och jag går sista året på Teknikprogrammet med inriktning Informations- och medieteknik, specialiserad mot mjukvaruutveckling.

Genom mina studier har jag utvecklat ett starkt intresse för webbutveckling och digitalt skapande, med tyngdpunkt på att kombinera estetisk utformning med teknisk funktionalitet.

För närvarande fokuserar jag på att stärka mina kunskaper inom backend-utveckling, främst genom fördjupning i Python och genom att utforska hur JavaScript kan användas för att skapa mer avancerad funktionalitet och interaktivitet på webben.
